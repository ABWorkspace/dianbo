# 电波 / Dianbo

连接第三方 AI 硬件、AI 软件与 Agent Harness 的跨设备、跨平台交互联动平台。

## 本仓库

本仓库用于逐步公开协议、SDK、适配示例和开发文档，以及收集问题与反馈。当前仅包含项目初始化资料，不包含完整产品源码；这些开发资源尚未发布。

完整产品目前在独立私有仓库中开发。公开接口和示例发布时会分别明确许可证；公开可见不代表已授予开源使用许可。

## 项目边界

- 通过各产品支持、授权的接口进行联动，不替代硬件厂商、语音软件或 Agent Harness。
- 优先本地运行，区分动作已发送、已被接受和已确认完成；无法确认时不宣称成功。
- 软件接入、硬件适配和跨设备能力均以实际发布与验证结果为准。

项目仍在早期建设中，尚无可安装的独立产品版本。
